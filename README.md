# Hospital Management System

A multi-role, database-driven hospital management system developed using **C#** and **SQL Server**.

## Overview
This project is a comprehensive hospital automation system consisting of **3 different user roles** and **15 separate forms**, designed to simulate real-world hospital workflows.

## User Roles
### Secretary (Admin)
- View and manage all patients
- View and manage appointments
- Create and manage announcements
- Add new doctors
- Update existing doctors
- Create and manage doctor branches (departments)

### Doctor
- View assigned patients
- View personal appointments
- Update personal information
- Access all announcements

### Patient
- View appointment history
- View active appointments
- Create new appointments
- Update personal information

## System Structure
- 1 Database
- 6 SQL Tables
- Role-based login system
- Authorization-based page access

## Features
- Multi-user role authentication
- CRUD operations across multiple entities
- Appointment management system
- Announcement system
- Data consistency with SQL Server
- Windows Forms based UI

## Technologies Used
- C#
- Windows Forms
- SQL Server

## Notes
This project was developed for educational and portfolio purposes and focuses on role-based system design and database integration.
